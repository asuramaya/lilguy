# Prospect Notes

One file per company once it moves past `unresearched` in `companies.md`
(e.g. `caterpillar.md`, `pepsico.md`). Suggested contents per file:

- Program name and link to the current posting (or "not yet posted, watch
  [date]" per `timeline.md`).
- Eligibility requirements as stated (grad year, major, GPA if any).
- Application deadline / rolling.
- Anyone known at the company (alum, referral path).
- Interview format, if known from past cycles (Glassdoor/LinkedIn reviews).
