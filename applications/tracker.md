# Application Tracker Template

Copy this file (e.g. `applications/2027-cycle.md`) per applicant or per cycle
and fill in as you go. Keep one row per role, not per company, since some
companies post several distinct internship tracks.

| Company | Role / Track | Category | Posted / Found | Applied Date | Status | Next Action | Notes |
|---|---|---|---|---|---|---|---|
| | | Retail/Distribution / CPG / Industrial / Logistics / Auto | | | Not applied / Applied / OA / Interview / Offer / Rejected / Closed | | |

## Status definitions
- **Not applied**: on the radar, not yet submitted.
- **Applied**: submitted, no response yet.
- **OA**: online assessment sent (game-based test, case study, etc.).
- **Interview**: at least one interview scheduled or completed.
- **Offer**: offer extended.
- **Rejected**: declined by the company.
- **Closed**: posting pulled or cycle ended before applying.

## Weekly review prompt
- Anything in "Applied" for 3+ weeks with no movement: follow up once,
  politely, referencing the specific role.
- Anything in `companies.md` still `unresearched` for a company whose
  category is now in its posting window (`timeline.md`): move it forward.
