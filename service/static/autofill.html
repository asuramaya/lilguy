lilguy.win

Autofill, no extension required

Build a small profile.json file and keep it on your own computer -- nothing here is saved to a server, an account, or even this browser. Then drag the bookmarklet below to your bookmarks bar; clicking it on any application page opens a file picker so you can choose that file and fill the page instantly.

0. Optional: start from a resume or an existing profile.json

A PDF resume gets a best-effort guess at name, email, phone, school, degree, and GPA -- parsed entirely in your browser via pdf.js, never uploaded anywhere. A profile.json you downloaded before loads back in exactly as you left it, so you can edit it. Review everything below either way.

2. The bookmarklet

This link is the same for everyone — it carries no personal data at all, so it's safe to bookmark, copy, or share. Clicking it opens a small file picker right on the page; choosing your profile.json fills the page immediately, and nothing about it is remembered afterward -- you'll pick the file again next time, on purpose, every time.

⚡ lilguy autofill ← drag this to your bookmarks bar

On mobile, or if your browser blocks dragging: right-click (or long-press) the link above and choose "bookmark link" / "add to bookmarks."

Prefer a normal browser extension instead? See the Tampermonkey userscript version in the repo — same coverage, plus resume auto-attach, at the cost of installing a userscript manager first.
